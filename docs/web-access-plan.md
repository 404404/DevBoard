# 独立 Web 账号访问

用户选择：在本机应用创建独立账号，禁止公开注册。

- 身份契约/数据库：增加 web 身份与账号表，保留飞书与服务身份、历史归属。
- 服务端：本机能力令牌保护账号创建/停用/重置；公网仅登录，复用 Cookie、CSRF、Host/Origin 校验；HTTPS、scrypt 密码哈希、持久账号锁定和全局并发/速率限制。
- 网页：普通浏览器账号密码登录，飞书入口保留；任务/评论使用真实 Web 账号署名。
- 桌面：应用设置管理 Web 账号，通过已保护的本机 API 操作。
- 验证：迁移保留关系、错误密码/限流、账号撤销、匿名数据访问、CSRF、Web 创建任务/评论与前端登录回归。
- 隔离：所有实现与测试在本 worktree；不连接真实 Codex 执行桥，不启动真实任务。
